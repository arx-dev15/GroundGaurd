# GroundGuard ML Grounding Verification Service (`services/ml`)

The machine learning fact-checking and grounding verification subsystem of GroundGuard.

This service evaluates whether claims generated by an LLM are grounded in retrieved evidence chunks, flagging hallucinations, numerical mutations, date shifts, and causal fallacies.

---

## 🏛️ Architecture Overview

```
Claim + Evidence Chunks
          ↓
  [Text Preprocessing]
          ↓
  [DeBERTa-v3 Cross-Encoder]
  (or ONNX Runtime C++ Engine)
          ↓
  [Temperature Scaling Calibrator (T = 1.25)]
          ↓
  [Asymmetric Multi-Evidence Aggregator]
          ↓
  { label: "contradiction" | "entailment" | "neutral", scores, groundingScore }
```

## 🚀 Quickstart

### 1. Environment Setup
```powershell
cd services/ml
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Start the Service
```powershell
python src/main.py
```
The service will start on `http://localhost:8001`.
* Swagger API Docs: `http://localhost:8001/docs`
* Health Check: `http://localhost:8001/health`
* Model Info: `http://localhost:8001/model/info`

## 📡 API Contract

### `POST /verify` (Single Claim)
```json
{
  "requestId": "req_001",
  "claimId": "claim_01",
  "claim": "The company reported ₹80 Cr revenue in 2024.",
  "evidence": [
    {
      "chunkId": "chunk_01",
      "text": "The company reported annual revenue of ₹50 Cr in 2024."
    }
  ]
}
```

**Response:**
```json
{
  "requestId": "req_001",
  "claimId": "claim_01",
  "label": "contradiction",
  "scores": {
    "entailment": 0.0003,
    "contradiction": 0.9996,
    "neutral": 0.0001
  },
  "groundingScore": 0.0001,
  "modelVersion": "groundguard-deberta-v1-finetuned"
}
```

### `POST /verify/batch` (Batch Claims)
Verifies multiple claims from a generated response concurrently.

## 🧪 Training & Evaluation Pipeline

### 1. Generate Synthetic Perturbation Datasets
```powershell
python training/data_generator.py
```
Generates 9 contrastive categories (`numerical_swap`, `date_swap`, `entity_swap`, `negation`, etc.) into `datasets/processed/` and `datasets/evaluation/test.jsonl`.

### 2. Train Domain Fine-Tuned Model
```powershell
python training/train.py
```
Fine-tunes DeBERTa-v3 using AdamW ($2\times 10^{-5}$) with class-weighted cross-entropy loss `[2.0, 1.0, 1.5]`. Saves checkpoint to `models/groundguard-deberta-v1`.

### 3. Export to ONNX & Run Latency Benchmark
```powershell
python models/onnx_export.py
```
Exports graph to `models/groundguard-deberta-v1.onnx` and measures 50-iteration speedup (1.33x faster on CPU, 37.4% reduction in p95 tail latency).

### 4. Run 4-Way Comparative Baseline Benchmark
```powershell
python evaluation/baselines.py
```
Compares TF-IDF Cosine, Bi-Encoder (`all-MiniLM-L6-v2`), Pretrained DeBERTa, and Fine-Tuned DeBERTa. Automatically compiles `EVALUATION_REPORT.md`.

### 5. Run Automated Unit Tests
```powershell
pytest
```
Runs 8/8 automated test cases covering endpoints, edge cases, and reasoning traps.
